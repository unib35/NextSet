# 업데이트 내역

## 1.1.0 — 심사 중

- 휴식 중에도 설정을 열 수 있어요. 기본 휴식을 바꾸면 다음 휴식부터 적용돼요.
- 화면을 다듬었어요. 좌상단 '종료'를 길게 눌러 운동을 끝내고, 아래 프리셋 줄을 넘겨 10초~5분 중에 골라요.
- iOS 26 이상: 휴식이 끝나면 알람으로 울려 무음·집중 모드에서도 놓치지 않아요. '+30초 더 쉬기'로 조금 더 쉴 수 있어요.
- 휴식 끝 알림이 시간 민감 알림으로 와요. 꺼져 있으면 설정에서 안내해요.
- 새 앱 아이콘(라이트·다크·색조)과 새 잠금화면 위젯.
- iOS·iPadOS 18, watchOS 11 이상에서도 쓸 수 있어요.
