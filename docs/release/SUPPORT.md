# 다음세트 지원

자주 묻는 질문에서 답을 찾지 못하면 이메일로 알려 주세요.

## 타이머

### 휴식 시간을 바꾸려면

대기 화면 아래 프리셋 줄을 넘겨 10초~5분 중에 고르거나, 톱니바퀴 → 기본 휴식을 조절하세요.

휴식 중에도 설정을 열 수 있고, 바꾼 기본 휴식은 다음 휴식부터 적용됩니다.

### 운동을 끝내려면

휴식 화면 좌상단 ‘종료’를 길게(약 1초) 누르세요. 실수로 끝나지 않도록 짧게 누르면 끝나지 않습니다.

VoiceOver를 쓰면 확인 창이 뜹니다.

## 알림

### 알림이 들리지 않아요

앱의 소리 설정과 iPhone의 설정 → 알림 → 다음세트 → 알림 허용을 확인하세요.

> **iOS 26 이상** 알람으로 울려요 — 첫 휴식 때 알람 권한을 허용하면 휴식 끝이 알람으로 울립니다. 무음 모드나 집중 모드에서도 소리가 나고, ‘+30초 더 쉬기’로 조금 더 쉴 수 있습니다. 거부했다면 iPhone 설정 → 앱 → 다음세트에서 다시 켤 수 있습니다.

> **iOS 18 · 알람 끔** 알림으로 알려요 — 무음 모드에서는 진동만 옵니다. 집중 모드에서도 받으려면 설정 → 알림 → 다음세트 → 시간 민감 알림을 켜세요. 꺼져 있으면 앱의 고급 설정에 안내가 보입니다.

기기 음량과 Apple Watch 연결 상태에 따라서도 알림을 받는 방식이 달라질 수 있습니다.

### Apple Watch에서 시작한 휴식도 알림이 오나요?

휴식을 시작한 기기에서 종료 알림을 예약합니다. Apple Watch에서 시작하면 Watch에서 알림 권한을 허용해 주세요. iPhone에서 시작한 휴식의 알림은 iOS의 Apple Watch 알림 전달 설정을 따릅니다.

다른 기기에서 시간을 바꾸거나 종료한 내용이 전달되려면 연결이 필요합니다. 연결이 끊긴 동안에는 알림을 예약한 기기에서도 시간을 변경하거나 종료해 주세요.

### 마지막 3초 소리와 햅틱이 화면 밖에서는 나오지 않아요

마지막 3초 안내는 앱을 보고 있을 때 재생됩니다. 화면 밖에서는 시스템 알림으로 휴식 종료를 알립니다. 알림 권한, 집중 모드, 소리 설정에 따라 전달 방식이 달라집니다.

### 알림 예약 실패 안내가 보여요

휴식 진행 화면의 ‘다시 시도’를 누르세요. 계속 실패하면 휴식이 끝날 때까지 앱을 열어 두고, 시스템 알림 설정을 확인해 주세요.

## 잠금화면·위젯

### 화면을 꺼도 시간을 볼 수 있나요?

설정에서 Live Activity를 켜면 지원되는 환경의 잠금화면과 Dynamic Island에 타이머가 표시됩니다. iOS의 표시 정책에 따라 휴식 종료 표시가 늦어질 수 있습니다.

### 위젯은 어떻게 추가하나요?

톱니바퀴 → 모든 설정 → 위젯 추가하는 방법에서 안내를 확인하세요.

### 아이콘의 다크·틴트 모양을 바꾸려면

홈 화면 빈 곳 길게 누르기 → 편집 → 사용자화에서 다크 또는 틴트를 선택하세요.

## 기록

### 운동 기록은 어디에 저장되나요?

기기에 최근 30회 요약을 저장합니다. Apple Watch를 사용하면 연결된 기기 사이에 요약을 전달합니다. 개발자 서버에 업로드하지 않습니다.

### 운동 기록을 삭제하려면

최근 운동에서 휴지통을 누르세요. 연결된 다른 기기의 기록은 해당 기기에서도 별도로 삭제해야 합니다.
