# Local sound source

Place `boxing-opening-bell.mp3` here to rebuild the rest-end bell. The MP3 is intentionally excluded from Git; confirm its distribution rights before release.

From the repository root, run `python3 tools/audio/make_sounds.py` on macOS. This overwrites `countdown-beep.caf` and `rest-end.caf` in `NextSet/NextSet/Sounds/`.
